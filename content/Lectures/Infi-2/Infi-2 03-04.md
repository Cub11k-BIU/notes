# Definite integrals
## Riemann sum #definition 
$$
\displaylines{
\text{Let } [a, b] \subseteq \mathbb{R} \\
\text{Let } P = \Set{ x_{0}, x_{1}, \dots, x_{n} } \\
a = x_{0} < x_{1} < \dots < x_{n} = b \\
\text{Let } C = \Set{ c_{i} | \forall i \in [1, n]: c_{i} \in [x_{i-1} + x_{i}] } \\
\text{Let } \Delta x_{i} = x_{i-1} - x_{i} \\
S_{R}(f, P, C) = \sum_{i=1}^{n} f(c_{i}) \cdot (x_{i} - x_{i-1}) = \sum_{i=1}^{n} f(c_{i})\Delta x_{i} \\
S_{R}(f, P, C) \text{ is called a Riemann sum and is an approximation of area under function } f \\
\text{This sum is the best approximation when all chosen rectangles' areas tend to } 0 \\
\text{Let } \lambda(P) = \max\{\Delta x_{i}\} \\
\text{When } \lambda(P) \text{ tends to } 0, \text{ all } \Delta x \text{ tend to } 0 \text{ and thus all rectangles' areas tend to } 0 \\
}
$$
## Riemann-Integrable function #definition 
$$
\displaylines{
\text{Let } f \text{ be a function on } [a, b] \\
f \text{ is called integrable by Riemann if:} \\
1. \quad f \text{ is bounded} \\
2. \quad \forall P, C: S_{R}(f, P, C) \underset{ \lambda(P) \to 0 }{ \to } L \\
\\
\text{Same definition via sequences:} \\
f \text{ is integrable on} [a, b] \text{ if } \\
\forall \Set{ P_{n} }: \lambda(P_{n}) \underbrace{ \to }_{ n \to \infty } 0 : \forall \Set{ C_{n} }: S_{R}(f, P_{n}, C_{n}) \to L \\
}
$$
## Definite integral #definition 
$$
\displaylines{
\text{If such limit } L \text{ exists, it is called definite integral of } f \text{ on } [a, b] \\
\text{And denoted as } \int_{a}^{b} f(x)dx = L \\
}
$$
### Example
$$
\displaylines{
\text{Let } f(x) = C \text{ on } [a, b] \\
S_{R}(f, P, C) = \sum_{i=1}^{n} C\Delta x_{i} = C \sum_{i=1}^{n} \Delta x_{i} \\
\forall P, C: \sum_{i=1}^{n} \Delta x_{i} = \sum_{i=1}^{n} [x_{i}-x_{i-1}] = x_{n} - x_{0} = b - a \\
\implies \int_{a}^{b} f(x)dx = C(b-a) \\
}
$$
## Oscillation of a function #definition 
$$
\displaylines{
\text{Let } f \text{ be a bounded function on } I \text{ (for example on $[a, b]$)} \\
\text{Oscillation of } f \text{ is a measure of how function varies between its extreme values} \\
\text{And is denoted as } \omega(I) = \sup f - \inf f \\
}
$$
## Lebesgue criterion of Riemann-Integrability #theorem 
$$
\displaylines{
\text{Let } f \text{ be a bounded function on } [a, b] \\
\text{Then } f \text{ is integrable on } [a, b] \text{ iff} \\
\forall \Set{ P_{n} }: \lambda(P_{n}) \underset{ n \to \infty }{ \to } 0 : \sum_{i=1}^{n} \omega_{i}\Delta x_{i} \to 0 \\
\text{Where } \forall i \in [1, n]: w_{i} = \omega([x_{i}, x_{i-1}]) \\
\\
\text{Exaplanation (not proof):} \\
\boxed{ \implies } \text{ Let } f \text{ be integrable on } [a, b] \\
\implies \text{All Riemann sums tend to } L \\
\sum_{i=1}^{n} \omega_{i}\Delta x_{i} = \sum_{i=1}^{n} (\sup_{[x_{i-1}, x_{i}]} f - \inf_{[x_{i-1}, x_{i}]} f)\Delta x_{i} = \\
= \underbrace{ \sum_{i=1}^{n} \sup_{[x_{i-1}, x_{i}]} f \Delta x_{i} }_{ \text{Upper Riemann sum} } - \underbrace{ \sum_{i=1}^{n} \inf_{[x_{i-1}, x_{i}]} f\Delta x_{i} }_{ \text{Lower Riemann sum} } \to L - L = 0 \\
\text{Why is it not formal proof:} \\
\text{There might be no point } c_{i} \text{ such that } f(c_{i}) = \sup_{[x_{i-1}, x_{i}]} f \\
\implies \text{These sums might not be Riemann sums at all} \\
\\
\boxed{ \impliedby } \text{ Let } \forall \Set{ P_{n} }: \lambda(P_{n}) \underset{ n \to \infty }{ \to } 0 : \sum_{i=1}^{n} \omega_{i}\Delta x_{i} \to 0 \\
\sum_{i=1}^{n} \omega_{i}\Delta x_{i} = \sum_{i=1}^{n} (\sup_{[x_{i-1}, x_{i}]} f - \inf_{[x_{i-1}, x_{i}]} f)\Delta x_{i} = \sum_{i=1}^{n} \sup_{[x_{i-1}, x_{i}]} f \Delta x_{i} - \sum_{i=1}^{n} \inf_{[x_{i-1}, x_{i}]} f\Delta x_{i} \\
\sum_{i=1}^{n} \omega_{i}\Delta x_{i} \to 0 \implies \left\{\begin{array}{}
\sum_{i=1}^{n} \sup_{[x_{i-1}, x_{i}]} f \Delta x_{i} \to L \\
\sum_{i=1}^{n} \inf_{[x_{i-1}, x_{i}]} f \Delta x_{i} \to L \\
\end{array}\right. \\
c_{i} \in [x_{i-1}, x_{i}] \implies \inf_{[x_{i-1}, x_{i}]} f \leq f(c_{i}) \leq \sup_{[x_{i-1}, x_{i}]} f \\
\implies \underbrace{ \sum_{i=1}^{n} \inf_{[x_{i-1}, x_{i}]} f\Delta x_{i} }_{ \to L } \leq S_{R}(f, P, C) \leq \underbrace{ \sum_{i=1}^{n} \sup_{[x_{i-1}, x_{i}]} f \Delta x_{i} }_{ \to L } \\
\implies S_{R}(f, P, C) \to L \implies f \text{ is Riemann-integrable} \\
\text{Why is it not formal proof:} \\
x_{n} - y_{n} \to 0 \centernot\implies \left\{\begin{array}{}
x_{n} \to L \\
y_{n} \to L \\
\end{array}\right. \\
x_{n} \text{ and } y_{n} \text{ might not have a limit at all} \\
}
$$
